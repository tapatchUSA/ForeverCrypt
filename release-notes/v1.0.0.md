**ForeverCrypt 1.0.0** for Windows 10/11 (x64) · Free for personal use

### What's new

- Initial public release
- Public-key encrypted chat — swap keys once, paste FC1.… codes through any app
- ML-KEM-768 (NIST FIPS 203) post-quantum key exchange with XChaCha20-Poly1305 sealing
- Per-install random identity with a Randomize button; multiple windows get separate keys
- Connection fingerprints to verify it's really your friend
- Step-by-step Walkthrough explaining why it's safe, in plain language
- Four themes (TAPATCH / Vault / Ember / Void)
- Fully offline — no accounts, no servers, no telemetry
